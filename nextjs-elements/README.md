# Knoplus Next.js Elements

This is a Next.js duplicate of the original single-file `index.html` template picker.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Structure

- `app/` contains the Next.js route and global styles.
- `components/TemplateShowcase.tsx` contains the interactive template picker.
- `data/templates.ts` keeps template labels, copy, images, and links in one editable place.
