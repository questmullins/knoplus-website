# Toolkit logos that Simple Icons doesn't carry

Used by the Experience / Toolkit panel (`data/toolkit.ts`, `image` field). Every logo belongs to its owner and is shown only to name the product.

| File | Source |
|---|---|
| power-apps.svg, power-automate.svg | Microsoft's current logos, via github.com/loryanstrant/MicrosoftCloudLogos (`logos/power-apps`, `logos/power-automate`) |
| excel, outlook, teams, onedrive, sharepoint, forms (.webp) | Microsoft's current 512px logos from the same repository, trimmed and resized to 128px |
| microsoft.svg | Microsoft logo (stands in for Microsoft Graph), Iconify `logos:microsoft-icon` |
| illustrator.svg | Iconify `logos:adobe-illustrator` |
| pyinstaller.svg, inno-setup.svg, sql.svg | Iconify `vscode-icons` file-type icons |
| pipedream.webp | Pipedream app icon, supplied by Quest (2026-10-27), corners masked and resized to 128px |
