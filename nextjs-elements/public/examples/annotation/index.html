Print annotation builder

Every piece of packaging art goes to the printer with an annotation: the specs, the barcode and every ink on every panel. They used to be typed up by hand for each revision. The original tool pulled the latest revision from the database and drew the annotation straight into Illustrator. This one draws it here.
