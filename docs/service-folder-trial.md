# Main-site style trial on /revamp

This records the initial folder trial. The current scrolling, banner, platform-badge and linked-project behavior is documented in [scrolling-project-banners.md](scrolling-project-banners.md).

The `/revamp` landing page now uses the existing homepage's `app`, sidebar, template buttons, stage, photographic background, typography, menu and button styles. The original `/` page, `TemplateShowcase`, template data and shared global styles are unchanged. Scoped additions provide the nested service navigation and responsive project previews.

Navigation:

- Web Services
  - Websites → the five existing website templates, with links to their working pages and the existing template inquiry form
  - Web Apps → Freestyle and Insta-Post Maker, with direct working-tool links and project walkthrough links
- App Services
  - RoseWave → existing app project and gallery/print-shop concept
  - UpDate → existing app project
  - Textualize → app summary and `/revamp/textualize`, using the same service-showcase layout
- Consulting
  - Cellese → space for selected examples
  - Excel → space for selected examples

The Consulting overview also retains access to the existing illustrative Prepress Assistant page. No Prepress work is represented as a delivered Cellese case study. Company workbooks, customer data, diagnostics, and internal screenshots are not copied into this trial. Cellese and Excel examples remain explicitly pending selection.

Folders use nested disclosure buttons with expanded state and the selected path. Opening a branch closes sibling branches, so the sidebar stays manageable. Sidebar scrolling is independent of the logo and contact area. On phones, Browse services opens the same hierarchy; selecting a project closes it and focuses its heading. Escape closes the menu, and resizing back to desktop restores access to the stage. Hash links restore the selected project and its parent folders, including browser Back/Forward.

The earlier warm consulting-grid component remains in source for reference. Existing walkthrough and gallery routes continue to work. The trial stays noindex.

Textualize's summary is based on the local `G:\Code\TextCommand\README.md`: styled text shortcuts and Android home-screen boards. No old Text Command screenshot, personal information, pricing, or release claim is published.
