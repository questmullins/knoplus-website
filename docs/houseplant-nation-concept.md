# Houseplant Nation website concept

Preview: `/revamp/websites/houseplant-nation/index.html`, linked from Web Services → Websites → Houseplant Nation in `/revamp`.

Derived from our existing `public/templates/homey-coffee` template. Its CSS is retained as `template.css`; the original template is unchanged. Local overrides add the plant shop palette, café menu rows, actual business details, responsive navigation, keyboard handling, and reduced-motion support.

Public source inspected and downloaded on 2026-10-24: https://houseplantnation.square.site/

The source homepage provides three photographs, business hours, address, telephone, email, drink categories, and links to its Canva menu, Square gift cards, Peerspace event listing, and social profiles. The original homepage HTML is archived locally at `.preview-tools/houseplant-nation-source/source.html` (ignored). This is a content/layout adaptation, not a copy of Square's checkout or private store data.
