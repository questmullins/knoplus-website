# App walkthrough recordings — October 19, 2026

All ten UpDate chapters and eight RoseWave chapters have silent loops recorded from the running Android 15 capture emulator. Every loop is between 2 and 5 seconds, normalized from the emulator recording timestamps. The page uses compact H.264 MP4 versions. GIF downloads and published GIF assets have been removed at the owner's request. WebP posters remain for loading and reduced-motion viewing.

Only the current visible section plays. Other clips load when they first enter view and pause when off screen, when another section becomes current, when the tab is hidden, or when the visitor pauses the loops. Reduced-motion preferences default to paused playback.
