# Consulting page concept

Review route: `/revamp`. The current homepage and its navigation remain intact.

This is a proposal for broadening Kno.plus from website building to a consulting practice that can take the form of websites, mobile apps, browser tools, and workflow improvements.

The page moves from the visitor's reason for coming, through an explanation of the thinking, into a filterable collection of projects, and ends with an email invitation. It intentionally avoids numbered process steps, pricing packages, invented results, and testimonials.

The four project examples draw from the repository's project-screen documentation and existing website and Insta-Post experiences. The artwork is illustrative; it does not represent current product screenshots. Project details say this explicitly. Project links are included only for experiences available in this checkout.

The route has its own CSS module, metadata, and noindex setting while it is a review concept. It inherits the existing root layout. No deployment configuration or contact delivery behavior changes.

Validation: production static export, desktop and 390px phone layout review, category filtering, project expansion and closing, section navigation, and contact link inspection.
