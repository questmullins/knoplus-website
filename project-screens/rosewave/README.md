# Rosewave screens

Feeds `/projects/rosewave` and the `/apps/rosewave` story. Portrait phone screenshots, no device frame. Only free photos may appear at full quality, and no prices.

| File | Screen | Used for |
| --- | --- | --- |
| `main.png` | Full-screen photo viewer | Hero, story 01 |
| `set.png` | Set as wallpaper: home, lock or both | Story 02 |
| `bare.png` | A Rosewave photo as the lock screen | Story 03 |
| `gallery.png` | Gallery of releases | Hero, story 04 |
| `set-tiles.png` | One release with its free photo marked | Story 05 |
| `next.png` | A members photo with the unlock button | Story 06 |
| `rotation.png` | Rotation settings | Story 07 |
| `menu.png` | The menu | Story 08 |
